# 首页导航：功能扩展清单

以下是适合当前个人导航的候选功能，供后续挑选，不代表全部开发。

现有的网站编辑、自动图标、Lucide 图标、网站拖拽、跨设备同步、配置导入导出和 Cloudflare 额度卡片不重复列入。

## 一、建议优先做

| 新增功能 | 使用效果 | 做到什么程度 |
| --- | --- | --- |
| 快速搜索网站 | 网站多了以后，输入名称或网址快速找到入口。 | 点击搜索按钮或按快捷键打开浮层，支持键盘选择；首页保持简洁。 |
| 多个网站栏目 | 把常用网页分别放进不同的卡片，例如「常用」「工具」「影音」。 | 以独立栏目呈现，不做图标文件夹；支持栏目命名和网站跨栏移动。 |
| 栏目拖拽排列 | 自己决定网站卡片、额度卡片和以后小组件的位置。 | 只在自定义模式拖动，保留苹果风格网格和手机端顺序。 |
| 上传网站图标 | 除自动获取和 Lucide 外，也能使用自己保存的 Logo。 | 上传图片后预览、裁剪，限制图片大小；保留透明背景。 |
| 自定义背景 | 在设置里更换背景颜色或壁纸。 | 默认仍是当前红色，支持本地上传、预览和恢复默认，不加壁纸商店。 |
| 批量添加网站 | 一次粘贴多个网址，减少逐个添加的操作。 | 导入前列出名称、地址和重复项，确认后添加；获取不到名称时允许手填。 |
| 删除后撤销 | 误删网站后可以马上恢复。 | 操作后短暂显示「撤销」，恢复原位置和图标。 |
| 最近配置备份 | 改乱布局或误导入配置后，可以恢复之前的状态。 | 保留少量最近版本，恢复前显示时间和网站数量，避免无限积累。 |

## 二、可以新增的小卡片

所有新卡片都从「添加拼贴」里选择，默认不强行放满首页；沿用现有圆角、半透明材质和响应式布局。

| 新增卡片 | 显示内容 | 合理范围 |
| --- | --- | --- |
| 日期与时钟 | 当前时间、日期、星期。 | 一张简洁小卡片，可选是否显示秒，不做花哨翻页动画。 |
| 待办事项 | 几条日常待办，支持新增、勾选和删除。 | 跨设备同步；内容多时展开查看，不做项目管理和复杂提醒。 |
| 便签 | 临时记一句话、一个地址或几条备忘。 | 先做纯文本、自动保存和跨设备同步，不做完整笔记软件。 |
| 设备概览 | NAS、路由器或 VPS 的在线状态、CPU、内存和存储概况。 | 优先读取已有监控的数据，点击进入原管理页；不重复做监控系统。 |
| 服务器流量余额 | 查看已有流量统计中的已用量、剩余额度。 | 有稳定读取接口后接入，只展示用量，不展示节点参数或订阅凭证。 |
| 天气 | 指定城市的当前天气、温度和简短预报。 | 手动设置城市即可，定位作为可选项；先确定数据来源再接入。 |

## 三、后续顺手完善

| 新增功能 | 使用效果 |
| --- | --- |
| 额度卡片显示项设置 | 自己选择首页重点显示哪些指标，完整明细继续保留。 |
| 网站打开方式设置 | 可选择当前标签页或新标签页打开，默认沿用现在的新标签页。 |
| 手机添加到主屏幕 | 补齐应用图标和独立窗口显示，作为常用入口；访问数据仍需登录。 |
| 深色外观 | 在设置中选择浅色、深色或跟随系统，同时调整玻璃材质和文字对比度。 |
| 保存冲突时保留草稿 | 另一台设备修改配置后，本机尚未保存的内容仍能保留，方便重新处理。 |

## 四、推荐下一批

如果只做一小批，建议按这个顺序：

1. **快速搜索**：网站越多越实用，页面改动也小。
2. **上传网站图标**：和现有编辑功能直接衔接，方便统一图标外观。
3. **自定义背景**：补齐目前自定义入口里最自然的一项设置。
4. **多个网站栏目 + 栏目拖拽**：等网站数量明显增加后一起做，避免只增加分栏却不能方便调整。
5. **待办或便签，先选一个**：增加一张真正会经常使用的小卡片。

## 五、暂不扩展的方向

- 多用户、角色权限、社交分享等与个人使用距离较远的功能。
- 内置 AI 聊天、文件管理、下载管理等已有独立服务的完整应用。
- 大量第三方小组件、自动播放内容和常驻装饰文字。
- 为显示状态而频繁扫描内网；没有可靠监控数据时，不把访问失败直接判断成设备离线。
- 内外网双地址自动切换仍按此前决定暂缓，等确实有使用需求再考虑。
